# ELHB benchmark release notes

## 1.0.0 - 2026-08-13

Development release of the owned long-horizon benchmark contract.

- Adds four versioned multi-stage tasks with Docker environments, hidden deterministic verifiers, and Oracle fixtures.
- Adds capability and Ever-only resilience lanes with immutable paired plans and semantic fault triggers.
- Adds durable-event, side-effect reconciliation, resume, native-platform, artifact-integrity, and report contracts.
- Adds human-baseline and two-reviewer quality schemas. The `full` release gate remains closed until real independent evidence is checked in; all current tasks are development proxies.

Results are comparable only when the benchmark version and resolved digest match.
